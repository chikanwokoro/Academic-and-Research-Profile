# Chika Nwokoro | Academic Portfolio

A responsive, single-page academic portfolio for GitHub Pages. The original interactive hanging ID badge, flip interaction, section order and visual structure are retained. Typography has been refined to a more mature academic pairing (IBM Plex Sans and Source Serif 4).

## Files
- `index.html` — portfolio content and page structure
- `style.css` — visual design and responsive layout
- `script.js` — ID badge flip, intro transition and typewriter animation
- `chika-portrait.jpg` — portrait used only on the introductory ID badge
- `documents/Chika-Nwokoro-Academic-CV-2026.pdf` — academic CV

## Publish on GitHub Pages
Upload the contents of this folder to the root of the `chikanwokoro.github.io` repository. In Settings → Pages, select the `main` branch and `/ (root)` if using branch deployment.

## Notes
- The portrait appears only once, on the front of the introductory ID badge. The About section is text-only.
- GlycoGraph-ML figures reflect 485 successfully parsed structures out of 500 (97%); the project remains ongoing.
- Publication cards are not linked to substitute PDFs. Add the correct publication files only when confirmed.
- Google Fonts are used for typography; system fallbacks are included.
