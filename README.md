# Chika Nwokoro | Academic Portfolio

A responsive, single-page academic portfolio designed for GitHub Pages.

## Files
- `index.html` — portfolio content and page structure
- `style.css` — visual design and responsive layout
- `script.js` — ID badge flip, intro transition and text animations
- `documents/Chika-Nwokoro-Academic-CV-2026.pdf` — academic CV
- `images/` — add a professional portrait here when ready

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of `chikanwokoro.github.io`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Your site should appear at `https://chikanwokoro.github.io`.

## Add your portrait later
When ready, add your photo to `images/` and name it `chika-portrait.jpg`. The two portrait placeholders in `index.html` can then be replaced with an image element using `src="images/chika-portrait.jpg"`.

## Before publishing
Please verify the research statistics (500 structures examined and 100% reported parsing success), dates, role descriptions and publication status. The glycan illustration is a generic visual motif, not a depiction of a specific glycan or a claim about the project's final dataset.
